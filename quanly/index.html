    Đổi tên đăng nhập / mật khẩu

    Áp dụng cho mọi máy. Mật khẩu cũ hết tác dụng ngay khi lưu xong.

    Kết nối GitHub

    Trang này sửa thẳng repo . Cần một token GitHub có quyền ghi vào repo này. Token chỉ nằm trong trình duyệt của anh.

    1. Mở trang tạo token (loại Fine-grained).
    2. Repository access: Only select repositories, chọn .
    3. Permissions, mục Repository: Contents: Read and write. Bấm Generate rồi chép token.

    Đã có tên đăng nhập và mật khẩu. Token cũ hết hạn và anh vừa dán token mới? Gắn token mới vào mật khẩu.

    Đặt tên đăng nhập và mật khẩu (tuỳ chọn)

    Lần sau chỉ cần gõ tên và mật khẩu, khỏi dán token. Điền lại ở đây khi đổi token mới.
